# Copy style

Write for a miner who wants an answer, not for a company presentation.

- Name the thing: Z15 Pro, 200,9, pool fee, stratum server, block target, product page.
- Say what the reader can do: compare pools, enter an electricity price, open the vendor page.
- Put the limit beside the claim. If a figure is old, estimated, missing or supplied by an operator, say so there.
- Show trust with a source and a date. Do not call material “trusted,” “transparent,” “source-backed” or “live” as a substitute for evidence.
- Prefer one complete sentence to a slogan split into fragments.
- Avoid vague nouns such as “ecosystem,” “landscape,” “journey,” “solution” and “experience.”
- Avoid empty adjectives such as “practical,” “robust,” “seamless,” “comprehensive” and “powerful.”
- Avoid “unlock,” “empower,” “navigate,” “leverage,” “revolutionize” and similar marketing verbs.
- Use `n/a` only for a value that was not published. Use `0` when the source published zero.
- Keep ownership, paid-placement and data-limit disclosures in plain English.

Good: “A Z15 works on Equihash 200,9. It cannot mine a 144,5 network.”

Bad: “Navigate the wider Equihash ecosystem with source-backed hardware intelligence.”
